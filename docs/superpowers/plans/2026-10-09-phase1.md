# PulsePay Phase 1 implementation plan

**Goal:** Implement the supplied ChaosLoop Phase 1 baseline in this repository.
**Architecture:** PostgreSQL owns money and a transactional outbox. Redis is optional cache and at-least-once transport. Separate workers, HTTP activity, and a read-only snapshot verifier expose independent signals.
**Execution:** Inline, checkpoint order 0, A, B, C, D, E as directed by the user. Work in the supplied current repository. No later-phase machinery.
**Spec:** User's complete Phase 1 implementation specification supplied 2026-10-09 is authoritative.

Python 3.12+, async SQLAlchemy/asyncpg, Pydantic v2, integer minor units, immutable ledger, bounded operations. Docker-only operator commands, non-root runtime, no Docker socket mounts. Preserve existing license and ignore rules. Missing verification remains unresolved.
